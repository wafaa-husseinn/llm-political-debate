# LLM Political Debate

A Gradio app where two LLMs debate the politics of a country you type in. One model argues for the government, the other argues for the opposition. Both are instructed to back up what they say with real statistics and name their sources.

The debate is capped at 10 rounds (a round = one government turn + one opposition turn).

## Models

Both models run on Groq's free API tier (OpenAI-compatible endpoint):

- Government: `openai/gpt-oss-120b`
- Opposition: `openai/gpt-oss-20b`

These can be changed in `.env` if Groq updates its model list.

## Running it

```bash
git clone https://github.com/<your-username>/llm-political-debate.git
cd llm-political-debate
python -m venv venv
venv\Scripts\activate      # on Mac/Linux: source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env       # on Windows: copy .env.example .env
```

Open `.env` and add your own Groq API key, then:

```bash
python app.py
```

Go to `http://127.0.0.1:7860`, enter a country, pick a number of rounds, and click Start debate.

## Files

- `app.py` - the Gradio app and debate logic
- `requirements.txt` - dependencies
- `.env.example` - template for the API key (the real `.env` is not committed, see `.gitignore`)

## Notes

The API key is read from an environment variable, not hardcoded. Statistics generated by the models should be treated as a starting point, not a verified fact - always check the cited source before relying on a number.
